## ✏️ EDITING & FORMS

### **Q: Can I edit text in multiple fields at once?**
**A:** No, edit one at a time:
1. Click field
2. Edit text
3. Click next field
4. Edit that text
5. When done with everything, click Save & Publish

---

### **Q: What happens if I leave fields blank?**
**A:** Most fields can be blank (they're optional):
- Tagline - can be blank
- Testimonial - can be blank
- Delivery note - can be blank

BUT these are required (can't be blank):
- Contact phone ⚠️
- Contact email ⚠️
- Hero headline ⚠️
- Page title ⚠️

---

### **Q: Can I undo changes?**
**A:** Once you click Save & Publish, changes are permanent.
- No undo button
- If you make a mistake, just edit it again and re-save
- Easy fix!

---

### **Q: What's the maximum length for text?**
**A:** Generally no limit, but:
- Headlines: Keep under 60 characters (fits on mobile)
- Descriptions: Keep under 150 characters (punch)
- Stories: Can be longer (up to 500+ words)
- Use your best judgment - shorter is usually better!

---

### **Q: Can I copy text from Word or Google Docs?**
**A:** Yes, but be careful:
- Copy from Word/Docs
- Paste into dashboard
- Sometimes formatting gets weird
- If it looks bad, delete and retype manually

## 🖼️ IMAGES

### **Q: What image formats work?**
**A:** These work great:
- ✅ JPG
- ✅ PNG
- ✅ WebP

These don't work:
- ❌ BMP
- ❌ GIF (usually)

**Pro tip:** JPG is best for photos, PNG for transparent images.

---

### **Q: What size should images be?**
**A:** These sizes are ideal:
```
Hero Banner: 1200x400 pixels (3:1 ratio)
Gallery: 600x400 pixels (3:2 ratio)
Products: 800x800 pixels (1:1 square)
```

But honestly: Any size works! Dashboard resizes automatically.

---

### **Q: How many images can I upload?**
**A:** No limit! Add as many as you want:
- 5-10 is ideal
- More = better (shows more work)
- First image is biggest, so choose your best!

---

### **Q: Can I reorder images?**
**A:** Yes! Edit the order:
1. Go to gallery section (Step 5)
2. Delete unwanted images (click X)
3. Click "Add Image" to add new ones
4. New images appear at bottom
5. Rearrange by deleting and re-adding in order
6. Save & Publish

---

### **Q: Where do I get image URLs?**
**A:** Free image sites:
```
1. Unsplash.com (best)
2. Pexels.com
3. Pixabay.com
4. Imgur.com (upload your own)
5. Your own website
```

**How to get URL:**
1. Find image you like
2. Right-click on it
3. Choose "Copy image link" or "Copy image address"
4. Paste in dashboard

---

### **Q: Image isn't loading / shows broken**
**A:** Try this:
1. Check image URL is complete
2. Make sure it starts with `https://`
3. No spaces or weird characters
4. Try opening URL in new tab (does image show?)
5. If image doesn't show in new tab, link is broken
6. Try different image

**Pro tip:** Test image URL in new browser tab first!

---

### **Q: Can I upload images directly?**
**A:** No direct upload in dashboard, but:
1. Use imgur.com (free, no account)
2. Upload your image there
3. Get image link
4. Paste in dashboard

Or ask admin to host image on your server.
