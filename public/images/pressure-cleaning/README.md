# Pressure Cleaning Gallery Images

Place your before/after photos here. Recommended filenames:

| Filename | Description |
|---|---|
| `services-flyer.jpg` | Services overview / promotional flyer |
| `driveway-before-after.jpg` | Driveway before & after |
| `roof-before-after.jpg` | Roof before & after |
| `paving-before-after.jpg` | Paving/stairs before & after |

Once images are placed here, add them via the Admin CMS at `/admin/pressure-cleaning` → Storefront Editor → Gallery Images.
Use the path format: `/images/pressure-cleaning/filename.jpg`
