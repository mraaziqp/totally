# Deep Cleaning Gallery Images

Place your before/after photos here. Recommended filenames:

| Filename | Description |
|---|---|
| `carpet-before-after.jpg` | Carpet before & after deep cleaning |
| `sofa-before-after.jpg` | Sofa/couch before & after upholstery cleaning |
| `mattress-before-after.jpg` | Mattress before & after |
| `vehicle-before-after.jpg` | Vehicle interior before & after |

Once images are placed here, add them via the Admin CMS at `/admin/deep-cleaning` → Storefront Editor → Gallery Images.
Use the path format: `/images/deep-cleaning/filename.jpg`
