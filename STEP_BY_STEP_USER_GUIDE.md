## 🆘 Part 8: Troubleshooting

### **Problem: Can't Login**

**What to try:**
1. Check caps lock is OFF
2. Password is: `totally2026` (exactly this)
3. Don't copy-paste - type it manually
4. Try different browser
5. Clear browser cache (Ctrl+Shift+Delete)
6. Try again

**Still stuck?** Email: admin@cleandeep.co.za

---

### **Problem: Changes Not Saving**

**What to try:**
1. Scroll to bottom
2. Find big green button
3. Click it (not just once, really click it)
4. Wait 5-10 seconds
5. Don't click multiple times
6. Button should return to normal
7. Go to live site and refresh (Ctrl+R)
8. Do you see changes?

**Still not working?** Try different browser or email admin

---

### **Problem: Image Not Loading**

**What to try:**
1. Check image URL is complete
2. Make sure it starts with: `https://`
3. Try a different image URL
4. Copy the image link carefully (no spaces)
5. Test URL in new browser tab
6. Does image show? Then paste in dashboard

**Tips for image URLs:**
```
✓ Good: https://images.unsplash.com/photo-12345
✓ Good: /images/deep-cleaning/photo.jpg
✗ Bad: images.unsplash.com/... (missing https://)
✗ Bad: Spaces or extra characters
```

---

### **Problem: Email Test Failed**

**What to try:**
1. Check email spelling
2. Click send again
3. Wait 30 seconds
4. Check SPAM folder
5. Try different email address
6. Try again

**Still failing?** Contact admin@cleandeep.co.za
