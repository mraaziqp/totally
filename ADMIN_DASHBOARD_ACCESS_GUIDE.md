### What You Can Do:
- ✅ Test your email service

- ✅ View email configuration

### How to Test Email:
1. Click **Email Manager** tab
2. Enter your email address in the test box
3. Click **Send Test Email**
4. Check your inbox (wait 1-2 seconds)
5. Should see a test email within seconds

### Expected Test Email:

## 🆘 **Troubleshooting**

### **Issue: Can't login**
**Solution:**
- [ ] Double-check password (case-sensitive)
- [ ] Ensure Caps Lock is OFF
- [ ] Try again
- [ ] Contact admin if still stuck

### **Issue: Email test failed**
**Solution:**
- [ ] Check internet connection
- [ ] Try again in 30 seconds
- [ ] Check spam folder
- [ ] Verify email address is correct
- [ ] Contact admin if persists

### **Issue: Image won't upload**
**Solution:**
- [ ] Check file format (JPG, PNG, WebP)
- [ ] Ensure file is under 10MB
- [ ] Try a different image
- [ ] Refresh page and retry
- [ ] Contact admin if stuck

### **Issue: Changes not appearing**
**Solution:**
- [ ] Click **Save** (must save to apply)
- [ ] Refresh page (Ctrl+R or Cmd+R)
- [ ] Wait 30 seconds (server sync)
- [ ] Check live storefront
- [ ] Contact admin if not working
